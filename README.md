# 🎵 Music Recommendation App

An Android app that recommends personalized music by analyzing user preferences using Firebase Firestore and integrated Machine Learning models. Built with Kotlin, Jetpack Compose, and modern Android development tools.

---

## 🚀 Features

- 🔍 Personalized music recommendations using ML
- ☁️ Firebase Firestore for storing user data and preferences
- 🖌️ Responsive UI with Jetpack Compose
- ⚡ Offline support with Room Database
- 🔄 Asynchronous programming with Kotlin Coroutines
- 🌍 REST API integration using Retrofit

---

## 🛠️ Tech Stack

- **Language**: Kotlin  
- **UI**: Jetpack Compose  
- **Backend**: Firebase Firestore  
- **Local Storage**: Room Database  
- **Networking**: Retrofit  
- **Concurrency**: Kotlin Coroutines  
- **ML Integration**: Custom recommendation logic
